# Mini-Games

As part of the **Mini-Games** assignment, two games have been implemented:

- **Guess Number**
- **Hangman**

## Implemented Features

- Implemented the **Guess Number** game.
- Implemented the **Hangman** game.
- Implemented **random answer selection** for both games.
- Implemented **difficulty levels** for both games.
- Both games are implemented using **Object-Oriented Programming (OOP)** principles.

## How to Run

To start the games, run the following command in the console:

```bash
python index.py
